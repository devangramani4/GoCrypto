# GoCrypto demo

A live demo of the GoCrypto trading platform: spot, perpetual futures and options, with the real
matching engine, risk engine and live order books running behind the web app.

**Sandbox only.** Prices are simulated and deposits are pretend money. Nothing here touches real
funds or real crypto, and everything you create is wiped when the demo restarts.

To try it: sign up with any email address, open **Wallet → Deposit** to add simulated funds, then
trade on any market.

Source code: https://github.com/devangramani4/GoCrypto (built from `infrastructure/demo/Dockerfile`).
